# Video script (≤5 min) — fill in once there's something real to show

Structure per the official submission requirements — hit every beat, don't pad:

1. **Problem + simple baseline** (~45s) — what the problem actually asks for, in
   plain terms, then what the baseline does and why that was the first
   reasonable path (not the only one).
2. **One realistic execution, start to finish** (~2 min) — run it live, on a
   real input, not a cherry-picked toy case. Show the agent workflow actually
   driving it (a moment of `hackathon-sprint`/`hackathon-fix` running is more
   convincing than describing it after the fact).
3. **Final comparison** (~1 min) — baseline vs. advanced, the actual number from
   `eval/score.py`, not a vibe.
4. **Changelog walkthrough** (~45s) — briefly explain `CHANGELOG.md`: the change
   that contributed the most to the delta, and one experiment that was tried
   and removed (the Rule Book explicitly asks for this — it's evidence of a
   real search, not a straight line to the answer).
5. **Close** (~15s) — main failure mode still present, and a hot take.

Fill in the specifics once `baseline/`, `advanced/`, and `CHANGELOG.md` have real
content — this is the shot list, not a draft script.
